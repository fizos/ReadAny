# Mac 高保真 PDF 试用说明

适用：Apple Silicon（M1/M2/M3 等）、macOS 14 或更新系统。

## 安装与首次启动

1. 退出已有 ReadAny，将 DMG 中的 ReadAny 拖到「应用程序」，再启动。
2. 本包为临时签名、未经过 Apple 公证。若系统阻止，请在确认来源后按 macOS 的「隐私与安全性」提示允许打开；不需要关闭系统安全保护。
3. 打开有文字层的 PDF，在翻译菜单中选择「高保真 PDF 翻译（实验）」，按提示初始化。

Python、依赖、字体和布局模型已内置；初始化不需要 Homebrew、系统 Python 或依赖下载。请预留约 2 GB 可用磁盘空间，以及整本导出需要的额外空间。实际翻译仍需要联网访问你配置的 AI 接口，并可能消耗接口额度。

先放入「应用程序」再初始化，避免移动应用后重建私有运行环境。安装包不包含你的接口 Key、书库或翻译记录。新版仍使用原应用标识，不是独立的并行安装版，安装前建议备份重要数据。

## 请在 M1 上确认

- 正文页可以翻译；目录、列表和代码没有明显错位或覆盖。
- 翻译中翻页、取消、关闭应用后，没有持续占用 CPU 的 Python 任务。
- 返回已翻译页显示缓存；放大、缩小、翻页正常。
- 退出后重新打开，仍可使用翻译和已有缓存。
- 整本导出保存到新文件，页数正确，原 PDF 没有改变；有意覆盖已有译文时会先确认。

自动化构建使用合成 PDF 和本地模拟 AI 接口检查集成路径，不代表已验证你 M1 上的阅读界面、真实书籍排版或真实 AI 接口。扫描 PDF 的 OCR 不在本次支持范围内。

反馈时请提供 macOS 版本、应用构建清单中的 source_commit、出问题的页码和截图；不要发送 API Key。若初始化失败，请保留界面的错误信息，不要先删除书库或重装系统 Python。
